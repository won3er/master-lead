# MLeads

Busca de empresas por segmento e cidade, com contatos públicos, para quem vende sites e serviços digitais.

## Para quem é
Profissionais e agências que prospectam pequenos negócios, principalmente os que ainda não têm site.

## O que faz
- **Busca de empresas**: digite o tipo de negócio e a cidade e receba a lista de empresas com WhatsApp, telefone e e-mail públicos.
- **Destaque de quem não tem site**: identifica os negócios sem site, os melhores alvos para oferecer um.
- **Criar site na hora**: gera uma prévia de site para a empresa encontrada, pronta para mostrar na abordagem.
- **Mensagens de abordagem**: modelos com variáveis (nome da empresa, bairro, cidade, segmento) para contato pelo WhatsApp.
- **Funil de contatos**: acompanha cada empresa por etapa até virar cliente.
- **Assinatura simples** com reembolso automático e cuidados com a LGPD (exportar e remover dados, lista de não contato).
